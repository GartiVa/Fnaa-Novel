# Five Nights at Animatronics (Текстовая новелла)

Фанатская текстовая игра по мотивам Five Nights at Freddy's, написанная на Python.

## Авторы
- Кудреватых Сергей
- Коржаков Константин
Группа: П-3-25

## Описание
Вам предстоит продержаться 4 ночи в роли ночного охранника пиццерии. Следите за камерами, экономьте энергию и защищайтесь от аниматроников.

## Как играть
Запустите файл `game_v2.0.py` в терминале:
python game_v2.0.py
